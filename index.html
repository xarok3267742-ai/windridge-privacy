Об игре и данных

«Хребет ветров: слоты» — бесплатная игра для взрослых с виртуальными очками, слотами и походом по горному маршруту. Денежных ставок, депозитов, покупок, вывода денег и материальных призов нет. Учётная запись не нужна. Игра работает на устройстве без подключения к серверу разработчика. В приложении нет рекламы, аналитики и автоматической отправки отчётов разработчику. Игровые данные не собираются разработчиком и не передаются ему.

В закрытой папке приложения сохраняются виртуальные очки, выбранная ставка, последний результат и статистика вращений, бонусы, настройки звука, вибрации и анимации, отметка о прохождении стартового экрана, 12 коллекционных целей. Для похода дополнительно сохраняются провизия, верёвка, выбранная ветка, пройденные ветки и этапы, число попутных отметок. Эти сведения нужны для продолжения игры с прежнего места и не обмениваются на деньги. Приложение не запрашивает дату рождения и не проверяет документы.

Разрешения и хранение

Приложение использует разрешение на вибрацию только для игрового отклика; вибрацию можно выключить в настройках. Звук воспроизводится локально. Микрофон, камера, контакты, геопозиция и рекламный идентификатор не используются. Автоматическое резервное копирование данных приложения отключено. При распространении через Google Play сам магазин может проверять источник установки согласно своим условиям; это не передаёт игровое сохранение разработчику.

Локальные данные остаются до очистки данных приложения или его удаления. Для удаления откройте настройки Android → приложения → «Хребет ветров: слоты» → хранилище → очистить данные либо удалите приложение. Названия пунктов могут отличаться на устройствах. Серверной копии прогресса нет.

Если сохранение повреждено, приложение предлагает восстановление. Только после явного подтверждения прежние данные копируются в локальный файл восстановления и создаётся новое сохранение. Если копию создать не удалось, сброс отменяется. Копия не отправляется наружу и удаляется при очистке данных приложения или удалении игры. Само восстановление с копией не означает полного удаления данных.
